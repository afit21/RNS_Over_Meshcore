'fieldtests/raw' 
Intent of the 'fieldtests/raw'  directory is to dump raw logs from field tests.
Every directory under 'fieldtests/raw' will be the named after the version the tests
were commpleted on. The notes.txt file in each if included will contain a brief informal journal of
situations the field tests were conducted in and will try to include time stamps.
The names of other text files will contain a beif description of which device the logs belong too

The snapshot number will change every time I feel the experimental branch has had enough changes to warrant a new set of field tests.

'fieldtests/reports'
The field tests will contain .md files generated by Claude outlining key findings 


Rules and tasks for Claude while generating reports:
- The overall goal of the reports is to be a historcal record of performance and a reference to make design decisions and code changes based off of.
- Reports are to be purely informational based on the logs and context provided
- Do not attempt to come up with recomendations for fixes or performance improvements
- If context is missing from logs that you think would give more context, feel free to make a note in the report
- Speculations about why something was performing badly can be noted, but please mention any context that is missing for a full picture
- If you think any information should be added in the report for future agents or developers to be aware of then feel free to add it
- Check out the changelog. If you think that a change was significant good or bad, let me know
- Feel free to include recomendations for future tests in the report
